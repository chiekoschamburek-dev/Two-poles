## 双极工作台

- **桌面（≥1024px）**：两栏并排，各占一半；栏内"身份条 + 今日主标题 + 视图切换 + 可滚动身体 + 另一极脚注"。
  两栏之间用 14px 间隙分开，不画贯穿竖线——它们本来就是两块独立界面。
- **手机 / 平板（<1024px）**：两张卡片上下叠放，前卡占视口高度减去底部 88px 预览条，后卡只露出顶部一条边。
  点预览条或其中的「切换」会交换两张卡；交换后焦点移到新前卡的标题区域，`aria-live` 播报当前前卡。
- **两仪怎么连起来**：`services/bridgeRules.ts` 只做**同期对照**，不做因果推断：
  - 今日：训练了但餐食没记、记了餐食但运动没记、两边都空、两边都有记录；
  - 本周：只有运动 / 只有餐食 / 两边都记了几天 / 训练日与无训练日的食物类别覆盖差（样本 ≥2 天才给）；
  - 任一天报了不适，安全提示排在最前，且不声称会"自动加量"或改餐；
  - 底部"合"区展示今日数字、本周双极环与最多两条联动提示；「展开协同」打开完整对照与免责清单。
- **跨栏联动**：每栏脚注显示另一极的今日摘要，点「去看看」在桌面端高亮另一栏、在手机端交换卡片；
  两栏身份条上的「协同」直接打开对照弹层。
- **每日养生**：每次整页进入时以居中弹窗出现；X 只关这一次，「今日不再出现」写入本机日期、当天不再自动弹。
  关闭后落到左侧图标脊下方的「养生」小卡片，点开后贴着导航浮在主页上（无遮罩，可随时关）。
  手机端小卡片在抽屉底部，点开会先收起抽屉再浮出卡片；清除全部数据会一并清掉“今天不再出现”的标记。
- **导航分组**：左侧图标脊按「运动 → 计划 / 跟练」「饮食 → 记录」分成两级；「两仪」和「周报」留在第一级。
  分组标题带对应极色圆点，当前分组会点亮；计划 / 跟练 / 记录的激条也分别用运动陶土、饮食松石。
- **运动深页**：`/plan`、`/execution` 与计划草稿弹窗里的强调色统一收成运动陶土——日历今天/选中、
  重算与模型按钮、阶段负荷条、进度条、计数、RPE、校准按钮、演示骨架与实时骨架线都不再使用全站松石；
  success / caution / danger 仍保留为语义色。
  手机抽屉显示同一套分组与全称；首页「两仪」只在精确停在 `/` 时高亮，进下钻页不会误亮。
- **空状态**：未建档时运动栏顶部保留建档引导；两栏都把"未记录"显示为未记录，不补 0。

## 设计系统（UI 3.0 + 双极）

- **令牌**：`src/styles/tokens.css`。纸面 `#f2f1ec`、墨 `#11161a`；交互强调色仍是 `#0f766e`；
  两极身份色为运动陶土 `#a34d28` 与饮食松石 `#0f766e`，各带 soft / line / strong 与深色提亮值；
  左栏底色、顶线与数据条用陶土，右栏用松石，文本用 `*-strong` 保证对比度。深色主题整组覆盖同名令牌，组件零感知。
- **原子**：`.micro`（10px + `.17em` 大写小标签）、`.num`（等宽数字）、`.hairline`。
- **表面只有两种**：纸面（`BaseCard default/flush`）与仪表面（`BaseCard variant="ink"`）。
- **组件**：`BaseButton`、`BaseCard`、`StatusBadge`、`InsightCard`、`ToastRegion`、`TwoPoleDial`、
  `StatStrip`、`ShapeState`；本轮新增 `PoleShell`、`PoleTabs`、`PoleMark`、`MovementPole`、`NutritionPole`、
  `BridgeBand`、`BridgeDialog`。
- **外壳**：86px 图标脊（窄屏变抽屉）+ 58px 纸面页头 + 浮动胶囊底栏；`/` 让主区吃满视口、自己处理滚动。

## 服务层

`planRules`（按档案生成，条件无解时如实返回冲突）、`mealRules`（类别覆盖 / 完整度 / 常吃 / 免责清单）、
`weekRules`（周报聚合，缺 RPE 不计入而不是补 0）、`loadRules`（负荷 / ACWR / 强度分布）、
`bridgeRules`（运动 × 饮食同期对照，本轮新增）、`foodComposition`（56 条目录 + 单位↔克数换算）、
`exercises`（动作库 + 场地/器材/限制过滤）、`demoCameraService`（按组时间线 + `summarizeSession`）。

## 已知欠账

1. **跟练页识别-计数仍未联动**：实时模式能跑 MediaPipe、能画骨架与角度，但计数仍由预设时间线推进（界面已写明）。
2. **`MetricCard.vue` 是待删空壳**：UI 3.0 后无调用方，构建产物里也不再有它的 chunk；本机删除受文件权限限制，`git rm` 一次即可。
3. **`DashboardView.vue` 已不参与路由**：内容已拆进两极；文件暂时保留作对照，确认后 `git rm` 即可。
4. **`UI/README.md`、`UI/完成总结.md`、`UI/开始使用.md` 未逐句校对**，可能仍残留 2.x / 单页 3.0 的描述。
5. **没有 ESLint / Prettier 配置**（历史上被误写过"ESLint 就绪"）。
6. **真机与键盘可达性未系统验证**：布局层有 ARIA，双极切换有 `inert` / `aria-hidden` / `aria-live`，
   但手机端交换后的 Tab 顺序与真实读屏仍未逐个点过。
