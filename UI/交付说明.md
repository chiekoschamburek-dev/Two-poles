## 💾 本地存储

设计中的存储结构：
```javascript
key: 'twopoles_state'
value: {
  mode: 'public' | 'athlete',
  profile: UserProfile
}
```

⚠️ 实际行为：`init()` 会在 AppShell 挂载时**读取**该键，但**运行时不会产生写入**——`switchMode()` 与 `updateProfile()` 是唯一的写入点，而它们没有任何调用方。所以"刷新页面后自动恢复状态"目前只能通过手工改 localStorage 来验证（本文档修订时即用此方式核对运动员模式的界面分支）。训练、饮食、周报数据完全不落盘。
